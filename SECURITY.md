# Security policy

## Supported versions

During pre-1.0 development, only the latest code on `main` receives security fixes.
Earlier commits and releases are not supported.

## Reporting a vulnerability

Report suspected vulnerabilities privately through GitHub's
[Report a vulnerability](https://github.com/CheeseGrinder231/homepool/security/advisories/new)
page. Do not report vulnerabilities in public issues, pull requests, or discussions.

Include:

- The affected commit or version and relevant configuration.
- A description of the vulnerability and its potential impact.
- Steps to reproduce it, with a minimal proof of concept if possible.
- Relevant logs or error messages, with credentials, secrets, and personal data removed.

Keep vulnerability details private while the report is investigated and a fix is
prepared. Disclosure can be coordinated in the private GitHub report.
